## ✨ Fitur

### ⚔️ Main
- **Attack Position** — Pilih posisi serang (Under / Behind / Above)
- **Auto Hold Egg** — Auto hold egg
- **Auto Hit Egg** — Auto pukul egg
- **Auto Hit Chest** — Auto pukul chest
- **Auto Attack** — Serang musuh otomatis
- **Auto Skill 1-5** — Pakai skill otomatis
- **Auto Lobby When Full** — Balik lobby pas inventory penuh

- **Mode Selector** — Dungeon / Tower / Cave
- **Map Selector** — Pilih map (Starless Island, Frozen Valley, dll)
- **Hell Mode + Inferno** — Toggle kesulitan tinggi
- **Party System** — Auto create party, auto invite
- **Tower Progress** — Track floor & vouchers
- **Cave Tickets** — Counter tiket cave
- **Auto Open Doors** — Buka pintu otomatis
- **Auto Replay** — Ulang dungeon otomatis
